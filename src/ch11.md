# 11. Динамическая диспетчеризация

> Глава в работе. Ниже её план из программы курса: темы, связь с C и с железом, задачи. Полный текст по образцу [главы 6](ch06/index.md) появится на шаге 3.

**Темы.** dyn Trait, толстые указатели (данные плюс vtable), содержимое vtable: drop, size, align, методы. Совместимость с dyn (бывшая object safety), where Self: Sized. `Box<dyn>`, &dyn, Any и downcast, приведение к супертрейту (trait upcasting).

**Как в C.** struct file_operations в ядре Linux как vtable, собранная вручную.

**Железо.** Косвенный вызов и предсказатель косвенных переходов, девиртуализация в LLVM. Цена защиты от Spectre v2 (retpoline) для косвенных вызовов.

**Трюки и ловушки.** enum и match вместо dyn, когда набор типов закрыт. &mut dyn FnMut без аллокации. Обобщённый метод делает трейт несовместимым с dyn.

**Задачи**

- A. Предскажите размеры &dyn Trait, `Box<dyn Trait>`, &str, `Box<[u8]>`, `Rc<dyn Trait>`, &&dyn Trait и объясните каждый.
- B. Постройте vtable вручную, как file_operations, и сравните ассемблер вызова с dyn Trait.
- C. Бенчмарк enum, dyn и обобщений для 2, 8 и 64 типов на перемешанном и отсортированном массиве. Объясните результаты через предсказатель переходов и счётчики perf.
- D. Извлеките vtable из толстого указателя и прочитайте из неё размер и выравнивание. Покажите, почему раскладка vtable не является стабильной гарантией и какие API для этого есть в std.
