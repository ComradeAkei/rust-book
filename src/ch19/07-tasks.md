## A. Три примитива на asm!

Реализуйте три функции встроенным ассемблером. Каждая показывает свою
тонкость операндов, которой не было в [19.1](01-asm.md).

```rust
{{#include ../../exercises/ch19/src/a_asm.rs:skeleton}}
```

- `rotate_left` — через `rol`. Счётчик сдвига `rol` берёт только из
  регистра `cl`, поэтому операнд — `in("cl")`, а не произвольный `reg`.
- `leading_zeros` — через `bsr` (индекс старшего установленного бита). При
  нулевом входе `bsr` не определён: ноль обработайте до ассемблера.
- `select` — `cond ? a : b` без ветвления, через `test` + `cmov`. `cmov`
  читает флаги, которые ставит `test`, поэтому у блока не должно быть
  `preserves_flags`.

```console
$ cargo test -p ch19-exercises a_
```

```rust
{{#include ../../exercises/ch19/src/c_memchr.rs:skeleton}}
```

Идея ([19.3](03-intrinsics.md)): `cmpeq_epi8` даёт `0xFF` в совпавших
байтах, `movemask` собирает их старшие биты в битовую маску,

([19.4](04-dispatch.md)) проверяет AVX2 один раз и кэширует выбор в
указателе на функцию. Сверьте результат со скалярным `iter().position`.

## D. Кооперативная сопрограмма

Соберите переключение контекста из [19.2](02-naked.md) и постройте на нём
две линии исполнения, которые по очереди передают управление друг другу.

```rust
{{#include ../../exercises/ch19/src/d_coroutine.rs:skeleton}}
```

`pingpong(rounds)` запускает сопрограмму на отдельном стеке; `main` и
сопрограмма `rounds` раз обмениваются управлением, каждая дописывая свой
номер в журнал. Для `rounds == 3` результат — `[1, 2, 1, 2, 1, 2]`.
Постройте naked-функцию `switch`, соберите стартовый кадр сопрограммы
вручную (шесть callee-saved значений и адрес входа сверху) и обменивайтесь
управлением в цикле. Сопрограмма входится по C-ABI без аргументов, поэтому
контексты, стек и журнал — общее состояние; доступ строго по очереди,
гонок нет.

Это упрощённый планировщик зелёных потоков. Настоящий добавил бы к нему
очередь готовых задач и таймерное прерывание для вытеснения — но ядро, сам
обмен регистрами и стеком, здесь уже целиком.
