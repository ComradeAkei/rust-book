# 17. Низкоуровневая работа с памятью

> Глава в работе. Ниже её план из программы курса: темы, связь с C и с железом, задачи. Полный текст по образцу [главы 6](ch06/index.md) появится на шаге 3.

**Темы.** MaybeUninit и инициализация по частям. ptr::read, ptr::write, copy_nonoverlapping, read_unaligned, read_volatile и write_volatile. NonNull, PhantomData для владения и вариантности. transmute и его безопасные замены, типы нулевого размера и типы динамического размера, slice::from_raw_parts, Layout, offset_of!, порядок байт.

**Как в C.** Каламбур типов через memcpy, flexible array member, volatile для MMIO, offsetof.

**Железо.** volatile запрещает удалять и сливать обращения, но не даёт атомарности и не упорядочивает обычные доступы, для этого нужен compiler_fence. Регистры MMIO, DMA-буферы и кэш данных на Cortex-M7.

**Трюки и ловушки.** Теги в младших битах выровненного указателя через map_addr. Инициализация большого массива сразу в куче, минуя стек. Ссылка на неинициализированную память уже UB, даже без чтения.

**Задачи**

- A. Для 8 вызовов transmute определите, какие корректны, какие дают UB и какие не скомпилируются.
- B. Разбор ELF-заголовка собственного бинарника без копирования: &[u8] в &Elf64Header с проверкой размера и выравнивания. Затем безопасная версия через from_le_bytes, сравните ассемблер.
- C. Тегированный указатель: 3 бита состояния в младших битах *const Node. Прогон под Miri со строгим provenance.
- D. Структура с заголовком и хвостовым массивом переменной длины как DST: выделение, инициализация, Drop и обоснование корректности. Сравните с заголовком плюс `Box<[T]>`.
