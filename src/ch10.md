# 10. Обобщения и мономорфизация

> Глава в работе. Ниже её план из программы курса: темы, связь с C и с железом, задачи. Полный текст по образцу [главы 6](ch06/index.md) появится на шаге 3.

**Темы.** Обобщённые функции и типы, ограничения и where, impl Trait в аргументах и возврате, const generics, turbofish. Мономорфизация, типы-маркеры, паттерн typestate.

**Как в C.** Макросы-шаблоны, void * и qsort с компаратором через указатель, который не встраивается.

**Железо.** Каждая инстанциация это отдельная копия кода, и на МК это прямо съедает flash. Встраивание через границу обобщения даёт выигрыш в скорости.

**Трюки и ловушки.** Внутренняя необобщённая функция против раздувания кода. Typestate для протоколов и периферии. Выражения над const-параметрами (N * 2 в типе) пока нестабильны.

**Задачи**

- A. Сколько копий функции окажется в бинарнике для данного кода? Проверьте через cargo-bloat и nm.
- B. Сравните qsort из libc с sort_unstable_by на 10 миллионах u32 по времени и ассемблеру компаратора. Объясните разницу встраиванием.
- C. Матрицы с размерностями в const generics, где несовпадение размерностей даёт ошибку компиляции. Измерьте рост кода при 5 разных размерах.
- D. Typestate-драйвер SPI-flash с состояниями «спит», «готов», «запись разрешена», «занят», где недопустимые переходы не компилируются. Оцените цену такого API в размере кода и удобстве.
