# 5. Времена жизни

> Глава в работе. Ниже её план из программы курса: темы, связь с C и с железом, задачи. Полный текст по образцу [главы 6](ch06/index.md) появится на шаге 3.

**Темы.** Аннотации и правила элизии, 'static и почему T: 'static не значит «живёт вечно». Ограничения T: 'a, времена жизни в структурах. Вариантность и PhantomData, HRTB `for<'a>`, GAT. Захват времён жизни в impl Trait по правилам edition 2024 и use<..>.

**Как в C.** Возврат указателя на локальную переменную, висячие указатели в структурах.

**Железо.** Времена жизни полностью стираются при компиляции. Данные 'static лежат в .rodata, а на МК во flash.

**Трюки и ловушки.** Разбор без копирования через &'a str и &'a [u8]. Box::leak для 'static при инициализации. &'a mut T инвариантен по T, и это источник самых загадочных ошибок.

**Задачи**

- A. Для 8 сигнатур без аннотаций восстановите полные времена жизни по правилам элизии.
- B. Токенизатор конфигурационного файла, возвращающий токены со ссылками во входной буфер. Тест подтверждает ноль аллокаций.
- C. Напишите функцию, которая компилируется только благодаря ковариантности. Затем оберните тип в Cell и объясните новую ошибку. Составьте таблицу вариантности для 10 типов.
- D. Одалживающий итератор (lending iterator) по перекрывающимся окнам &mut [T]. Покажите, почему стандартный Iterator этого не позволяет, и реализуйте его через GAT.
