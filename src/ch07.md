# 7. Обработка ошибок и паника

> Глава в работе. Ниже её план из программы курса: темы, связь с C и с железом, задачи. Полный текст по образцу [главы 6](ch06/index.md) появится на шаге 3.

**Темы.** Result и оператор ?, преобразование ошибок через From, трейт Error и цепочки source. Собственные типы ошибок, комбинаторы Option. Паника: раскрутка стека и abort, catch_unwind, #[panic_handler] в no_std, extern "C-unwind", #[track_caller].

**Как в C.** Коды возврата и errno, забытая проверка, setjmp и longjmp.

**Железо.** Таблицы раскрутки .eh_frame и цена unwinding. Нулевая цена на пути без ошибки. Маленький Result возвращается в паре регистров.

**Трюки и ловушки.** #[must_use], Infallible, panic=abort для уменьшения размера. Паника в Drop во время раскрутки даёт abort. Паника через границу FFI без C-unwind тоже завершает процесс.

**Задачи**

- A. Для 6 цепочек ? с разными типами ошибок определите, какие скомпилируются и каких реализаций From не хватает.
- B. Иерархия ошибок для парсера конфигурации из главы 5: ввод-вывод, синтаксис с позицией, семантика. Контекст и цепочка source без сторонних крейтов.
- C. Измерьте размер бинарника и .eh_frame при panic=unwind и panic=abort. Измерьте цену Result против кода возврата в горячем цикле и объясните по ассемблеру.
- D. Воспроизведите панику в Drop во время другой паники и объясните abort. Спроектируйте API буферизованного записывающего устройства, которое так упасть не может.
