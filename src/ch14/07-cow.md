# 14.7. Cow

`Cow<'a, B>` (clone on write) — значение, которое либо заимствовано,
либо принадлежит нам:

```rust
pub enum Cow<'a, B: ?Sized + ToOwned + 'a> {
    Borrowed(&'a B),
    Owned(<B as ToOwned>::Owned),
}
```

Для `B = str` владеющий вариант — `String`, для `B = [u8]` — `Vec<u8>`.
`Cow` нужен функциям, которые обычно возвращают вход как есть, а иногда
— изменённую копию. Вернуть `String` всегда — значит копировать
каждый раз; вернуть `&str` — нельзя, когда копия всё-таки понадобилась.

## Копия только для особых случаев

Имя канала в CSV надо взять в кавычки, если в нём есть запятая,
кавычка или перевод строки. В обычном имени их нет:

```rust
{{#include ../../code/ch14/src/cow.rs:csv}}
```

Нагрузка кадра SLIP (RFC 1055) — то же самое для байтов: экранирование
`ESC ESC_END` и `ESC ESC_ESC` встречается редко, и кадр без него
отдаётся подсрезом входа:

```rust
{{#include ../../code/ch14/src/cow.rs:unslip}}
```

Тест `unslip_borrows_without_escapes` проверяет, что для кадра без ESC
результат указывает в сам кадр — тот же адрес, — а `cow_allocates_only_when_owned`
в `code/ch14/tests/alloc.rs` считает обращения к распределителю: для
`csv_field("adc0")`, `lowercase("adc0")` и `unslip(&[1, 2, 3])` их нет
вовсе, `csv_field("a,b")` выделяет пять байт — три символа и две
кавычки, — а `lowercase("ADC0")` — четыре.

`Cow<str>` разыменовывается в `&str`, сравнивается со строками и
печатается, так что вызывающему обычно всё равно, какой вариант
пришёл. Если нужна `String`, `into_owned` скопирует заимствованное и
отдаст своё без копии.

## to_mut: копия при первой записи

`to_mut` возвращает `&mut` на владеющий вариант и, если `Cow` был
заимствован, сначала копирует:

```rust
{{#include ../../code/ch14/src/cow.rs:to_mut}}
```

Это та же идея, что у `Rc::make_mut`, только без счётчика: «есть ли
другие владельцы» `Cow` знает по варианту. Копирование при записи в ядре
устроено так же — `fork` отдаёт ребёнку те же страницы только для
чтения и копирует страницу при первой записи в неё.

<div class="box hood">

**Под капотом: размер Cow.** `Cow<str>` занимает 24 байта, столько же,
сколько `String`, хотя вариантов два (тест `observed_cow_size`, это
наблюдение). Тег спрятан в ёмкости `String`: она не бывает больше
`isize::MAX`, и значения ёмкости с установленным старшим битом
свободны — одно из них и означает `Borrowed`. Даже `Option<Cow<str>>`
укладывается в те же 24 байта. Раздел [6.4](../ch06/04-niches.md) разбирает,
как компилятор находит такие ниши.

</div>

<div class="box trap">

**Ловушка: Cow не ради Cow.** Если функция всегда меняет вход,
`Cow` только добавляет ветку: возвращайте `String`. Если почти никогда
— `Cow` хорош. Если вызывающий всё равно сразу делает `into_owned`, —
проще принимать `String` по значению и менять на месте. Сигнатура с
`Cow` в параметре (`fn f(name: Cow<str>)`) встречается реже: она нужна,
когда функция хранит значение и хочет избежать копии для литералов
`'static`.

</div>
