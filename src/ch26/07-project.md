# 26.7. Сквозной проект: станция без cortex-m-rt

До этой главы станция жила в тестах на хосте, а прошивки собирались на
готовой среде cortex-m-rt. Шаг главы 26 — прошивка станции
`firmware/ch26-station` на своей среде выполнения из `ch26-bare`:
таблица векторов, `Reset`, скрипт компоновки и semihosting — всё из
разделов [26.3](03-cortex-m.md) и [26.4](04-startup.md). Формат кадра —
тот же крейт `telemetry-frame`, что разбирает хост: `no_std` с
главы 6, он собирается в прошивку без единой правки.

```rust,ignore
{{#include ../../firmware/ch26-station/src/main.rs:main}}
```

Датчиков пока нет — их заменяет функция `sample`, пила с периодом в
секунду: драйверы и таймер появятся в главе 27. Станция кодирует восемь
кадров измерений, печатает первые два байт за байтом, разбирает каждый
обратно декодером и пересчитывает CRC по таблице из раздела
[25.7](../ch25/07-project.md):

```console
$ cd firmware && cargo run --release -p ch26-station
станция: среда ch26-bare, кадры telemetry-frame
кадр 0: a5 01 01 00 0a 00 90 86 01 00 00 00 00 00 d0 07 00 00
кадр 1: a5 01 01 01 0a 00 c1 f5 02 00 00 00 00 00 0c fe ff ff
кадров 8, разобрано обратно 8, CRC по таблице совпал 8
CRC16_TABLE по адресу 0x00000e98 — во flash, код запуска её не трогал
$ llvm-size target/thumbv7m-none-eabi/release/ch26-station
   text	   data	    bss	    dec	    hex	filename
   4760	      0	      0	   4760	   1298	target/thumbv7m-none-eabi/release/ch26-station
```

Кадр 0 по полям: маркер `a5`, версия `01`, тип `01` — измерение, номер
`00`, длина нагрузки `0a 00` — 10, CRC `90 86`. Нагрузка: датчик `01 00`,
время `00 00 00 00`, значение `d0 07 00 00` — 2000. У кадра 1 датчик 2 и
значение `0c fe ff ff` — −500 в дополнительном коде. Всё в порядке
little-endian, как задал формат в главе 6.

## Что изменилось по сравнению со средой cortex-m-rt

**Ни одного изменяемого `static`.** Счётчики, номер кадра и буфер — на
стеке `main`. Среда `ch26-bare` не готовит `.data` и `.bss`, и любой
`static mut` в станции остановил бы сборку проверкой из `ch26.ld`
(раздел [26.4](04-startup.md)). Колонки `data` и `bss` — нули.

**Таблицы — во flash, без кода запуска.** `CRC16_TABLE` — 512 байт в
`.rodata` по адресу 0xe98. Её посчитал компилятор (глава 25), и коду
запуска с ней делать нечего: неизменяемые данные читаются прямо из
flash.

**4760 байт.** Это вся прошивка: таблица векторов, среда, кодер и
декодер кадров, две реализации CRC и печать. Без `core::fmt`: числа и
байты печатают `sh::dec`, `sh::hex` и `hex2` станции.

**Один исходник на трёх ядрах.** Станция работает на Cortex-M0, M3 и
M4F — проверки `run-demos.sh` запускают её на всех трёх. Адрес таблицы на
M0 другой, 0xed8: другие инструкции, другой размер кода перед ней.

## Проверка

| Проверка | Что проверяет |
|---|---|
| `run-demos.sh`, «станция без cortex-m-rt» ×3 | восемь кадров закодированы, разобраны и сошлись по CRC на M0, M3, M4F |
| `exit(sent == 8 && …)` | QEMU завершается с кодом 1, если хоть один кадр не сошёлся |
| `ASSERT` в `ch26.ld` | изменяемый `static` в станции — ошибка сборки |
| тесты `telemetry-frame` | кодер, декодер и обе CRC — на хосте, под Miri и со случайной раскладкой |

Следующий шаг — глава 27: прерывания, драйверы периферии и таймер
вместо `sample`, и станция, которая отправляет кадры в [UART][g-uart] сама.
