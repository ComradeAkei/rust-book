# 4. Заимствование и ссылки

> Глава в работе. Ниже её план из программы курса: темы, связь с C и с железом, задачи. Полный текст по образцу [главы 6](ch06/index.md) появится на шаге 3.

**Темы.** &T и &mut T, правило «много читателей или один писатель». Перезаимствование, NLL, двухфазные заимствования (v.push(v.len())), раздельное заимствование полей. Срезы как толстые указатели, split_at_mut, авторазыменование в методах.

**Как в C.** restrict, strict aliasing, указатели в буфер, ставшие недействительными после realloc.

**Железо.** Атрибут noalias в LLVM и оптимизации, которые он открывает: удаление повторных загрузок, векторизация. Ссылка это указатель без null, поэтому `Option<&T>` занимает одно машинное слово.

**Трюки и ловушки.** Индексы вместо ссылок для графов: арена плюс u32-индексы. split_first_mut, chunks_exact_mut. Borrow checker отвергает часть корректного кода, например условный возврат заимствования. Метод заимствует весь self, а не отдельные поля.

**Задачи**

- A. Для 10 фрагментов определите, какие скомпилируются, и для остальных назовите код ошибки (E0499, E0502, E0506) до запуска компилятора.
- B. Напишите fn add_twice(a: &mut i32, b: &i32) и её аналог на C с restrict и без него. По ассемблеру найдите лишнюю загрузку в C-версии без restrict.
- C. Граф зависимостей сборки с циклами без unsafe и без Rc: арена и индексы, топологическая сортировка и вывод найденного цикла.
- D. Найдите корректную программу, которую текущий borrow checker отвергает. Объясните причину и проверьте её с экспериментальным Polonius на nightly.
