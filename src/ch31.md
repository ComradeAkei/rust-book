# 31. Надёжность: тесты, фаззинг, верификация

> Глава в работе. Ниже её план из программы курса: темы, связь с C и с железом, задачи. Полный текст по образцу [главы 6](ch06/index.md) появится на шаге 3.

**Темы.** Модульные, интеграционные и doc-тесты. Тесты для no_std на хосте и в QEMU. Property-based testing через proptest, фаззинг через cargo-fuzz, санитайзеры ASan и TSan на nightly, Miri и loom в CI. Проверка моделей через Kani, мутационное тестирование через cargo-mutants. Цепочка поставок: cargo-audit, cargo-deny, cargo-vet.

**Как в C.** Те же libFuzzer и санитайзеры, но без гарантий системы типов вокруг.

**Железо.** Тестирование прошивок без железа в QEMU, hardware-in-the-loop, детерминированные тесты логики прерываний.

**Задачи**

- A. Для 6 функций сформулируйте свойства и стратегии proptest.
- B. Фаззинг парсера IPv4 и TCP из главы 6 и токенизатора из главы 5: найдите внедрённую ошибку.
- C. Kani: докажите отсутствие переполнения и выхода за границы в кольцевом буфере из главы 21 для всех размеров до N.
- D. Мутационное тестирование сквозного проекта: найдите выжившие мутанты и допишите тесты. Опишите класс ошибок, который не ловит ни один из инструментов главы.
